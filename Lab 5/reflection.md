# Lab 5 Reflection

Static code analysis helps identify code quality, security, and formatting issues without executing the program.

Pylint checks code quality and programming practices. Bandit identifies common security vulnerabilities. Flake8 checks Python formatting and style.

The main improvements made were replacing unsafe serialization, using parameterized SQL queries, fixing the mutable default argument, improving exception handling, and handling an empty music catalog.

Using all three tools helps make code safer, more readable, and easier to maintain.
